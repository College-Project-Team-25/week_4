Topic: 72-Hour Electricity Generation Forecasting for Kelmarsh Wind Farm

================================================================================
PLAN 1: PROJECT SPECIFICATIONS
================================================================================
1. TOPIC & PROBLEM:
Wind power generation is intermittent and weather-dependent.
Grid operators need accurate 72-hour generation forecasts.
Kelmarsh Wind Farm has six Senvion MM92 turbines.
Inaccurate predictions cause grid penalties and imbalance.

2. RESEARCH QUESTION:
Can hybrid and pre-trained models outperform baseline neural networks?
Can numerical weather predictions reliably forecast turbine power?

3. OBJECTIVES:
- Ingest Kelmarsh SCADA and Open-Meteo UKMO forecast data.
- Develop a baseline Multi-Layer Perceptron neural network.
- Build a hybrid physical power curve and XGBoost model.
- Fine-tune a pre-trained time-series foundation model (Chronos).
- Optimise hyperparameters using Bayesian search.
- Deploy an interactive forecasting and AI explanation dashboard.

4. TARGETS & KPIs:
- Forecast Horizon: Hourly predictions up to 72 hours.
- Whole-Farm Accuracy: MAE <= 8% of rated capacity (12.3 MW).
- Baseline Improvement: Hybrid RMSE >= 10% lower than baseline.
- Pre-trained Transfer: Pre-trained MAE >= 8% lower than baseline.
- Dashboard Latency: Forecast inference under 2.5 seconds.
- Test Quality: Minimum 80% automated unit test coverage.

================================================================================
PLAN 6: MODEL DEVELOPMENT AND OPTIMISATION
================================================================================
Three machine-learning approaches will be developed and compared.

MODEL 1: MULTILAYER PERCEPTRON (MLP)
- Architecture: Feed-forward neural network (3 hidden layers, ReLU activations, Dropout).
- Inputs: Prepared weather features (wind speed u/v vectors, gusts, temperature,
  pressure) and historical SCADA power measurements.
- Output: Predicted hourly power output (kW) up to 72 hours ahead.
- Role: Primary neural-network baseline for comparison with the other approaches.
- Framework: PyTorch or TensorFlow/Keras.

MODEL 2: HYBRID AERODYNAMIC POWER CURVE AND XGBOOST
- Stage 1 (Physical): Aerodynamic power curve maps wind speed to expected turbine
  output using the Senvion MM92 rated power curve (cut-in ~3 m/s, rated ~12 m/s,
  cut-out ~25 m/s).
- Stage 2 (Statistical): XGBoost residual model learns the signed error between
  Stage 1 estimates and actual SCADA measurements, correcting for turbulence,
  yaw misalignment, wake effects, and seasonal deviations.
- Final Forecast = Power Curve Estimate + XGBoost Residual Correction.
- Aim: Improve forecast accuracy beyond what either physical or statistical
  modelling achieves alone.
- Framework: Scikit-learn power curve interpolation + XGBoost library.

MODEL 3: PRE-TRAINED CHRONOS FOUNDATION MODEL
- Base Model: Amazon Chronos (chronos-t5-small / chronos-t5-base), a pre-trained
  probabilistic time-series transformer trained on diverse real-world datasets.
- Adaptation strategy to be determined based on:
    * Input format compatibility with Kelmarsh hourly SCADA telemetry.
    * Computational requirements (GPU memory, inference latency).
    * Suitability for producing 72-step (72-hour) ahead point forecasts.
- Likely approach: zero-shot inference or lightweight fine-tuning on the
  Kelmarsh power time series using the HuggingFace Transformers library.
- Framework: HuggingFace Transformers + GluonTS / Chronos pip package.

BASELINE: PERSISTENCE MODEL
- Naive baseline: forecast = last observed power value repeated for 72 hours.
- Used to establish the minimum performance bar all models must exceed.

HYPERPARAMETER OPTIMISATION:
- Tool: Optuna (Bayesian / TPE sampler), 50 trials per model.
- Validation: TimeSeriesSplit cross-validation (chronological, no data leakage).
- Optimisation Objective: Minimise Mean Absolute Error (MAE) on validation fold.
- Final Evaluation: All models tested on the same held-out chronological test
  period for a fair, like-for-like comparison (MAE, RMSE, R2).
